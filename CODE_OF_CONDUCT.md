# Code of Conduct

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful and constructive in issues, pull requests and discussions. Harassment, personal attacks, discriminatory language and publishing others' private information are not tolerated.

## Enforcement

The maintainer reviews reports and may edit or remove comments, lock threads, or block accounts that break this code. Report a problem privately by opening a [private security advisory](https://github.com/aclemetson/mobile-idle-builder/security/advisories/new) titled "Conduct report", or contact the maintainer through their [GitHub profile](https://github.com/aclemetson).

Enforcement follows the Contributor Covenant's [community impact guidelines](https://www.contributor-covenant.org/version/2/1/code_of_conduct/#enforcement-guidelines).
