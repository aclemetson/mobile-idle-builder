## The World layer

A **World** wraps the multi-Site machinery one level up (the Physics-only "Quantum Domains" that first used it were retired 2026-11-24). Physics / Chemistry / Biology are three Worlds; each owns its own set of Sites, its own research (branch), and its own map theme. Only ONE world's ONE site is live ECS; everything else runs on idle snapshots (identical to the Site model — no multi-world ECS).

```
World (Physics)   ── sites[] ── grids[]   (live one, rest idle-snapshot)
World (Chemistry) ── sites[] ── grids[]   ← economic unlock: entropy + physics prereqs
World (Biology)   ── sites[] ── grids[]   ← economic unlock: entropy + chemistry prereqs
```

**Shared across all worlds** (one wallet each): entropy (per run), prestige currency ✦, crystals ◆, managers, prestige shop, achievements, net worth. **Prestige** resets all grids + research but **world unlocks survive** (like site unlocks). **Unlock is pure economic:** pay entropy + hold the prerequisite unlock from the prior world (no prestige-count gate).

`WorldSO` fields (proposed): `id`, `displayName`, `unlockCost` (entropy), `prereqUnlockIds` (research/item ids that must be unlocked), `siteIds` (member sites), `theme` (palette/tint for `GridRenderer`).

## World 2 — Chemistry

**Gate (2026-11-19, replaces the research gate described below):** Chemistry opens from **delivery tasks**, not research or entropy. `world_tasks` in `game_data.json` holds five stages (`WorldTaskSO`, `Resources/WorldTasks.asset`): Carbon; Helium-4 + Carbon; Li/Be/B; O/Ne/Mg/Si; N/Na/Al + Silicon. Items Maxwell's Demon consumes while a stage is active count toward it (they still pay entropy; idle chains ending at the Demon count at the idle rate). Stages survive prestige and are sized one per run, so Chemistry opens after about five prestiges. `world_chemistry.unlock_by_tasks = true`, `prereq_unlock_ids = []`; `WorldTaskService` unlocks it when the last stage finishes. Before the gate Physics reaches **Hydrogen to Silicon only and makes no molecules**: every research past that (heavy_elements, isotopes, fission, `fusion_iii` onward) and the whole Chemistry tree carry `required_world: "world_chemistry"` (`WorldGate`), and molecular/Chemistry buildings carry `world` so they are only built in Chemistry. Inside Chemistry, `chemistry_lab` (no prereqs) comes first, then `molecular_synthesis` (Molecular Synthesizer; liquid H2, water, methane, ammonia); the Element Harvester also collects nitrogen and silicon.

**Natural feedstock (2026-11-19, `scripts/chemistry_feedstock.py`, replaces the element seams below):** Chemistry mines elements the way nature leaves them, never loose atoms: `hydrogen_gas` (H₂, item 187), `oxygen_gas` (O₂, 188), `graphite` (C, 189), `nitrogen_gas` (N₂, 190), category `RawResource`. Each has a field (`field_type "Element"`, `world: world_chemistry`): `hydrogen_gas_field` (Hydrogen Seep) x3 and `oxygen_gas_field` (Oxygen Vent) x2 are on `site_chem_lab` from the start; `graphite_field` (Graphite Deposit, 200K) and `nitrogen_gas_field` (Nitrogen Vent, 500K) are bought from the Build menu, as are the Mineral Bed and Metal Lode (after `reaction_engineering`). A field bought later is still listed on the site at density 0: `FieldGenerator.KnownFields` only knows fields a site names, so an unlisted one could neither be sold nor restored from a save. `element_field_light` is retired. The Element Harvester is now the **Extractor** (id unchanged). Research order: `chemistry_lab` (Extractor, Molecular Synthesizer; water ← 2 H₂ + O₂ makes 2, liquid H₂ ← 5 H₂) → `molecular_synthesis`, shown as **Carbon Chemistry** (graphite; methane ← C + 2 H₂, CO₂ ← C + O₂, now in the Molecular Synthesizer) → `nitrogen_fixation` (N₂; ammonia ← N₂ + 3 H₂ makes 2) → `reaction_engineering`, which now also brings Na/Cl/S/Si mining, salt, sulfuric acid and the Compound Synthesizer. Every later Chemistry/Biology recipe takes the feedstock instead of atomic H/C/N/O, balanced (`output_quantity` 2 where the equation makes two). `ChemistryFeedstockTests` checks no Chemistry or Biology recipe uses loose atoms and that the first reactions balance. Not done yet: minerals and metals in their natural forms, Uranium Hexafluoride (needs Physics' uranium and fluorine), Nucleotide's phosphorus.

**Streams: Chemistry's rule tweak (2026-11-22, `scripts/chemistry_streams.py`).** Each world changes one rule of the standard game. Chemistry has **no eV power**: `world_chemistry.stream_transport = true` (`WorldSO.streamTransport`) turns every belt into a water stream.
- `WorldRules.Apply` (called first thing in `GridSaveService.LoadGrid`, so on load and every site/world switch) writes the `ActiveWorldRules` singleton and **disables Maxwell's Demon** (`Disabled` tag, cells freed, visual removed); leaving the stream world re-enables it. `DemonTag` marks the baked Demon; every fixture rule (kept on clear, never restored, never moved or demolished, its own panel) keys on it, not on `EntropySinkTag`.
- `ConveyorPlacer` adds `StreamSegment` to belts placed while the rule is on. The Build menu calls the belt tool "Channel"; channels draw in water colours (`ConveyorVisualizer.GetStreamMaterial`).
- A **Spring** (`spring`, building 29, `is_spring`, `stream_flow` 10 L/s) heads a stream at its output. A channel no Spring feeds is dry: nothing on it moves.
- Bank buildings: Chemistry reaction buildings have one input and one output on the same edge (input facing North, output facing South: the stream runs along the south side). `ConveyorSystem` stream passes: a bank building takes, as items pass, the first item its set recipe uses while that input is below cap (everything else floats past; no recipe = takes nothing); it drops products into the middle of its tile when there is a gap (`StreamRules.DropIndex`). Extractors (no ports, legacy output) drop the same way.
- **Flow**: every building with `flow_draw` (synth 3, reactor 4, forge 4, organic 5, extractors 1 L/s) gets `StreamConsumer` + `StreamStatus`. `StreamFlowSystem` walks each stream heads-first and shares the Spring's flow **upstream first** (`StreamRules.Take`; merges add flow); `ProductionSystem`/`CollectorSystem` run at `StreamStatus.Ratio`. A building beside no stream gets 0. HUD strip shows `Flow used / supplied L/s` (`StreamGridState`); the inspector shows the building's share ("Short of water", "Dry"); placing one away from a channel warns "No water".
- **Mouth**: a stream tail feeds sinks only. A **Calorimeter** (`calorimeter`, building 30, 2x2, `is_entropy_sink` + `is_placed_sink`) at the mouth burns arrivals at full value through `EntropySinkSystem`; an open mouth sells leftovers at the surplus fraction (`SurplusSale`). The Calorimeter saves/restores/demolishes like any building.
- **Offline**: `GridSaveService.RebuildIdleSnapshot` uses `StreamIdleAnalyzer` for stream worlds (same rules: ordered banks, upstream-first flow, input-limited crafts, Calorimeter full / open mouth surplus). Non-escaping byproducts (combustion's water) are not modelled offline yet.
- Generators and relays are `world_physics`. New recipe `methane_combustion` (CH4 + 2 O2 -> CO2 + 2 H2O, water as byproduct, `nitrogen_fixation`). The four feedstock `collect_*` recipes got their own ids 291-294 (they had copied `collect_sodium`'s 167).
- **Several Springs and streams (2026-11-27)**: a stream may have any number of Springs. A Spring pours into whichever stream tile its output faces (a head or mid-stream), and a branch drawn from a second Spring that ends on an existing stream tile joins it there; flows add from the join down. `StreamFlowSystem` groups tiles linked downstream into separate streams (`StreamNetworks`, union-find): each stream keeps its own supply, draw and Spring count, written to every building on it (`StreamStatus.StreamSupply/StreamDraw/StreamSprings`; the inspector shows "This stream: draw / supply L/s from n Springs", warning when over). A Spring beside no stream adds nothing. `StreamGridState` keeps the site totals for the HUD and adds `StreamCount` and `OverdrawnCount`; the flow strip warns "n stream(s) over its Springs" even when the total looks fine (`FormatFlowLabel`). Offline (`StreamIdleAnalyzer`) already added merging flows; saved branches run through to the mouth (`GridSaveService`), so they link.
- Tests: `StreamTests` (rules + ECS flow/pickup/drop/mouth/dry), `StreamIdleTests` (incl. a second Spring on a joining branch), `StreamNetworkTests`, `ChemistryStreamContentTests`.
- **Chemistry tutorial (2026-11-22, `scripts/chemistry_tutorial.py`)**: Chemistry runs its own 10-step tutorial (`world_tutorials` -> `WorldSO.tutorialFlow`, asset `Data/tutorial/tutorial_chemistry.asset`) the first time the player is there: welcome, Chemistry Lab research, Spring, Channel, two Extractors, Molecular Synthesizer set to Water, Calorimeter, first water, flow. **The Physics tutorial never runs in Chemistry**: `TutorialFlows.Activate` (from `GridSaveService.LoadGrid`) swaps `TutorialFlowSO.Current` to the live world's flow and loads its state into the shared `TutorialStateData`; progress is saved per world in `SaveData.worldTutorials` (survives prestige), Physics stays in `SaveData.tutorial`. `ECSLoadBridge` resets to the main flow before applying the Physics state on load; `FlushToSave` stores a world flow via `TutorialFlows.Store`; prestige ends only the main tutorial. The overlay resets (no "complete" toast) when the flow changes and shows each flow's `completion_message`. The unlock intro (`intro_world_chemistry`) is a short announcement again. Tests: `WorldTutorialTests`.
