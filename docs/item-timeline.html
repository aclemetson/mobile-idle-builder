Phases and pacing

Each phase spaces its items between its start and end day: a burst of quick items first (gap in active hours), then gaps that grow by "Gap growth" per item, with a longer finale. A wall stretches the gap before its item by its repeats.

Walls: prestige at the same spot

Like Idle Planet Miner: the research for the item costs more than one run earns. The player prestiges here "Repeats" times, and the listed upgrades are what make the next run break through. Upgrade prices below are set to match.

Prestige upgrades

Today's shop, extended, plus one track per world. Each track's top levels are what the later walls need, so a player always has an upgrade to aim at.

Ascension and the megastructure

Once every item is unlocked, Ascend: worlds lock again; items, research and prestige currency reset; shop upgrades stay. Each Ascension pays megastructure material. Each megastructure stage costs more material than the last and adds a permanent production bonus, so the next loop is faster (down to a floor). This projects the stages over the years.

Prices and time to create

Every item is priced the way the game prices recipes today: value = inputs + wage x craft time, so each craft earns about the wage. The wage (entropy per building-second) grows with active play hours. Research for an item costs the active time the timeline gives it (since the previous unlock in any world: entropy is one wallet) x the income of that moment: buildings x wage x the upgrade multiplier, which grows with every wall cleared. "Work" is the total building time one item takes, all the way from raw sources; "Slowest step" is how often one comes out with one building on each step (the step to multiply).
